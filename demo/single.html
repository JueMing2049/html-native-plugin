HNP v0.2.1
HTML Native Plugin

页面本来就会动，只是没人告诉它

一份 hnp.js 加一个 data-hnp，静态 HTML 就长出标签页、筛选、批注、决策卡。 不装任何东西，双击就能用；十二个插件各是一个文件，用哪个引哪个。

说白了：以前这些交互得靠一个框架、一个构建、一个服务器。现在只要一行 script，谁打开都能点。

标签页 筛选 对比滑块 决策卡 渐入与数字 滚动叙事 时间轴 就地批注 自检面板

01 · 标签页 tabs

一个注册制内核加十二个独立插件。每个插件只认自己的 data-hnp，互不知道对方存在。

<script src="hnp.js"></script> 之后写 <div data-hnp="tabs">，剩下的交给约定。

框架要编译、要产物、要部署。这里要的是一个能发邮件、能离线双击、十年后还能打开的 HTML。

02 · 筛选 filter

注册表、生命周期、幂等记账
选中即批、决策卡落库
拖拽对比、方向键切换
单文件内联、断网可用
零依赖、无构建也能跑

03 · 对比滑块 compare

不用 HNP

每个页面重写一遍事件绑定；换个人接手就得重新读一遍 boot()；多实例互相踩状态。

用 HNP

声明式挂载、可卸载、幂等；状态按插件命名空间隔离；坏插件只 warn 不拖垮页面。

06 · 滚动叙事 scrolly

一 · 写好 HTML

结构先站住，交互后加。没有 JS 也是完整的一篇。

二 · 贴 data-hnp

想要哪个能力，就在容器上写哪个名字，可以写多个。

三 · 交付

单文件内联后离线可开；要改就改源块，不要改产物。

结构

标题、段落、表格。此时没有任何脚本。

挂载

内核扫到 data-hnp，把对应插件装上去。

内联

css 与 js 内联进同一份 HTML，行为一致、可离线。

07 · 时间轴 timeline

STEP 01
内核先行

注册表、上下文、幂等记账先立住，插件才有地方挂。

STEP 02
插件跟进

每个插件只解决一件事，能单独引、单独卸。

STEP 03
降级兜底

动画可停、观察器可退、单插件失败不连坐。
